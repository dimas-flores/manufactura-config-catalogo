PROYECTO CONFIG SERVER Y CATÁLOGO

Repositorio propio privado: https://github.com/devmijaelflores-boop/manufactura-config-catalogo
Config Server lee config-data de ese repositorio, rama main.
PostgreSQL: localhost:5432 / ms_catalogo / postgres / clave de práctica 123456.

Definir GITHUB_TOKEN con permiso de lectura del repositorio antes de iniciar el Config Server. Si gh está autenticado:
export GITHUB_TOKEN="$(gh auth token)"

Iniciar primero ms-config-server: ./mvnw spring-boot:run
Después ms-catalogo-service: ./mvnw spring-boot:run
Swagger: http://localhost:8081/doc/swagger-ui.html
En Windows usar mvnw.cmd.

El DOCX original se conserva como referencia. La implementación ya usa el repositorio propio.
